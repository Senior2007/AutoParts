Каталог магазина в формате JSON

Партнеры выгружают наличие и цены по адресу /api/parts/. Доступ — по учетной записи магазина.

import requests

response = requests.get(
    'http://127.0.0.1:8000/api/parts/',
    cookies={'sessionid': SESSION_ID},
    timeout=5,
)
for part in response.json()['results']:
    print(part['name'], part['price'], part['quantity'])

Ответ: {"results": [{"name": "Термостат Valeo 87C", "price": "58.60", "quantity": 37}]}

Если сервис недоступен, магазин показывает запасной текст и записывает предупреждение в журнал.
