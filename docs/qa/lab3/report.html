План тестирования

Цель — проверить основную покупку и управление каталогом по требованиям ЛР1, установить воспроизводимость расхождений и собрать данные для решения о приёмке. Контрольная версия 305c4bf, macOS 26.6.2 ARM64, Python 3.14.0, Django 6.0.5, SQLite, локальные демоданные и синтетические фикстуры. Приоритеты требований назначены в плане по влиянию на покупку, права и склад. В ЛР1 приоритеты отсутствуют.

В успешность входят фактически выполненные PASS и FAIL. Для будущих блокировок BLOCKED и непройденных NOT RUN знаменатель выполнения остаётся равным полному плану. Формулы даны в общепринятом виде. Пособие с разделом 6.2 не было приложено к заданию.
