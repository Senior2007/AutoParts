Подготовка

Выполните команды из корня репозитория. Если виртуальное окружение ещё не создано, выполните инструкции из README.

.venv/bin/python -m pip install -r docs/qa/requirements.txt
npm --prefix docs/qa/lab4/ui ci --ignore-scripts

Для основных UI-сценариев нужен установленный Google Chrome. Для полного прогона совместимости один раз установите управляемые сборки Firefox и WebKit.

npm --prefix docs/qa/lab4/ui exec -- playwright install firefox webkit

Команды для демонстрации

Каждая команда использует код из текущей папки проекта. Для проверок с данными создаётся временная SQLite с демоданными. При необходимости команда запускает Django только на 127.0.0.1 и очищает временный стенд при завершении. Отчёты прогонов складываются в git-игнорируемую папку docs/qa/runs/. Точный путь печатается в начале.

Команды с тестами возвращают ненулевой код при проваленных ожиданиях. Сверяйте такие результаты с реестром дефектов. Для демонстрации без повторных прогонов можно открыть сохранённые отчёты из таблицы материалов.

Postman Desktop

.venv/bin/python -m docs.qa serve

Импортируйте коллекцию ЛР4, оставьте значение baseUrl равным http://127.0.0.1:8765 и запустите папки по порядку. Для нового прогона перезапустите стенд и очистите cookie тестового хоста в Postman. Этот же стенд подходит для ручной демонстрации сайта в браузере.
