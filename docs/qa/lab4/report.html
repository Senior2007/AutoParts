API в Postman

В коллекции покрыты маршруты UC-1–UC-9 и дополнительные FR-20/22, включая оба собственных JSON-эндпоинта. Коллекция проверяет HTTP-коды, значения и схему JSON, видимость SKU, формы, карточную оплату со скидкой, ЕРИП, счёт и отмену.

GET формы получает CSRF. POST входа проверяет Set-Cookie для sessionid, Postman передаёт полученную сессию через cookie jar, а следующая защищённая страница даёт токен для дальнейших POST. Идентификаторы товара, заказа, типа и производителя извлекаются из ответов. Проект использует сессионную аутентификацию Django.

UI-автоматизация

Пять функциональных сценариев Playwright выполнены в Chrome. Page Object разделяет регистрацию, каталог, корзину, оформление и профиль. Каждый сценарий получает собственный browser context, при необходимости генерирует отдельный товар и регистрирует уникального клиента. Ожидания основаны на состоянии URL, DOM и ответах. Конфигурация сохраняет при падении скриншот и trace.
